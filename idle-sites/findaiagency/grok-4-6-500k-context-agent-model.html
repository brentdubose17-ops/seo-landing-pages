Grok 4.6 Ships: SpaceXAI's 500K-Context Model Matches GPT-5.6 Sol at 60%+ Lower Price

Published August 13, 2026By ABD Legacy LLC
AI models

What happened. SpaceXAI (formerly xAI) released Grok 4.6 on August 12, 2026, positioning it for long-running agents and ambitious interactive and visual work. API pricing: $2 per 1M input tokens and $6 per 1M output tokens, with a fast variant at 2x. Artificial Analysis lists a 500,000-token context window and scores the model 61 on its Intelligence Index — matching GPT-5.6 Sol (max) at 61.

The pricing story. Against GPT-5.6 Sol ($5/$30 per 1M tokens), Grok 4.6 is 60%+ cheaper. On output tokens — the dimension that dominates cost in reasoning-heavy agent workloads — $6 vs $30 works out to 80% cheaper. Cache hits run $0.50 per 1M tokens (Artificial Analysis). The AI agency cost calculator now models Grok 4.6 with this verified pricing.

Why agent builders should care

  • A 500K context window lets a single agent hold a large codebase, an extended session history, or a multi-hour research loop in context.
  • Frontier-level intelligence at a lower output-token price makes Grok 4.6 a credible default for agent-heavy builds — and a concrete data point in any GPT-5.6 Sol-priced quote conversation.
  • It's available now in Cursor, Grok Build, the SpaceXAI API, OpenRouter, Vercel, and Cloudflare. Cursor and Grok Build include 2x usage for the first week.
