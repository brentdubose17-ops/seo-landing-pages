Anthropic shipped a new flagship on September 1, 2026: Claude Fable 5.1 is generally available, and Claude Mythos 5.1 is the same model with different safeguards, restricted to trusted-access programs for cybersecurity and life sciences work. The Claude Fable 5.1 price is $10 per million input tokens and $50 per million output tokens — unchanged from Fable 5 — but lower cache-read pricing makes typical workloads about 25% cheaper and highly agentic workloads up to ~45% cheaper.

For agencies, this is the first Claude release that pairs a real per-token price cut with a serious capability jump. Here is the pricing you can quote, how Fable 5.1 compares to Fable 5, Opus 5, and GPT-5.6 Sol, and where the Mythos access question changes what you can promise clients.

Claude Fable 5.1 price: $10/$50 per million tokens, cheaper cache reads

Anthropic's published API pricing for Claude Fable 5.1 (API ID claude-fable-5-1):

The cache-read cut is the headline. Fable 5.1 reads cached input at $0.25/1M versus $1.00 for Fable 5 — a 75% reduction. Anthropic estimates ~25% lower cost for typical token-billed workloads and up to ~45% lower for context-heavy agentic work, where cache reads dominate. Batch API keeps the standard 50% input/output discount.

Google's countermove landed the next day. On September 2, 2026 — the day after Fable 5.1 — Google released Gemini 3.8 Flash, its third Flash in six weeks, at $0.75/$3.75 per 1M through December 31 (introductory). Google calls it its best reasoning and coding model yet, says it tops the DeepSWE v1.1 leaderboard at a fraction of the cost of larger frontier models, and recommends it for software engineering and autonomous agent workloads — while Pro releases remain paused since early 2026. That makes the "cheapest frontier coding model 2026" conversation a four-way race (Fable 5.1, Sol, Grok 4.6, Gemini 3.8 Flash), and it is exactly why workload routing, not brand loyalty, is the agency skill that matters.

On Anthropic's published benchmarks, Fable 5.1 leads the coding pack: Terminal-Bench 4.0 at 55.8% (Fable 5: 42.0%, Opus 5: 52.3%, GPT-5.6 Sol: 37.3%), CursorBench 3.2.0 at 73.4% (Opus 5: 70.0%, Sol: 67.2%), and Terminal-Bench-Science 0.1 at 52.6% (Opus 5: 29.0%, Sol: 22.4%). Fable 5.1 is the strongest argument yet for the "best AI model for coding agents 2026" label — but the right pick still depends on workload (see our AI coding agent pricing guide and OpenAI vs Anthropic for business, plus the GPT-6 Astra computer-use comparison, for the full routing picture). Beyond coding: the Sept 4, 2026 reasoning milestone. On September 4, Anthropic announced that Claude produced the first computer-checked formalization of Fermat's Last Theorem in Lean — a 13M+ line proof completed in roughly 11 days, largely autonomously, which Anthropic calls "the largest Lean proof ever constructed." The run used an internal research model roughly comparable to Claude Fable 5.1 on the open Prove2Me platform, and the proof was machine-checked by Lean using only its three standard axioms. Kevin Buzzard's Xena blog — the formal-math community project that has been chasing FLT since 2024 — confirmed the result: "a gigantic proof (over 13.4 million lines of code)" that "took only 11 days." Coding benchmarks are not the whole Claude story: this is machine-verified reasoning on a centuries-old open problem, and it is the proof point to cite when clients ask whether Claude-class models can be trusted for verification-heavy knowledge work.

Claude Mythos 5.1 vs Fable 5.1: same model, different safeguards

The Claude Mythos 5.1 vs Fable 5.1 question is not about capability — they are the same model. The difference is the safety posture:

  • Fable 5.1 (GA): production safeguards for general use; API ID claude-fable-5-1; available on Claude API, Bedrock, Vertex, and Foundry.
  • Mythos 5.1 (trusted access only): safeguards tuned for cybersecurity and life sciences work; not publicly available; gated behind Anthropic's trusted-access programs (Project Glasswing participants), including a US-government-partnered biology access program with enrollment for scientists expected soon.

Anthropic also cut false positives: its newest cyber safeguards block 60% fewer benign requests than before, and Fable 5.1 can now help discover software vulnerabilities — though not develop exploits. That is a direct answer to the over-refusal complaints that dominated Claude discourse in late August.

When Mythos access matters for your clients

Mythos 5.1 matters when the client's work lives where general safeguards throttle it:

  • Cybersecurity practices — penetration testing, vulnerability research, secure code review, incident response analysis.
  • Life sciences and biotech — research, assay design, literature synthesis, regulatory review.
  • Defense-adjacent and government work — the biology track is explicitly run in partnership with the US government.

For everyone else, Fable 5.1 with production safeguards is the answer. Mythos is a procurement conversation for a narrow client set, not a general tooling decision — plan on trusted-access application cycles, not a public launch.

Claude Fable 5.1 is the first genuinely cheaper flagship: same $10/$50 list price, but cache reads at a quarter of the cost make agentic workloads materially cheaper, with the best coding benchmark scores Anthropic has published.
